# Code and game-logic review · 28 September 2026

Reviewed the Lantern Picnic repository at baseline 95472a3. Local main, GitHub main and the additional local worktree had no newer Claude changes at the start of this review.

## Findings addressed

- **P2 — A cancelled secret-wish timer could reveal a newer wish early.** Serve Momo an orange, Undo before her delayed request, then serve again. The old callback deleted the new pending marker before checking its cinematic token. The entire callback now uses the token guard; Undo clears pending callbacks' presentation state and existing bubbles. The browser regression checks that the wish stays hidden past the old deadline and reveals at the new one.
- **P2 — An unknown graphics setting could prevent startup.** A malformed saved quality or URL override reached scene code that expects a known quality tier. Unknown values now fall back to automatic selection before world construction.

- **P2 — Riddles could consume most of a narrow phone screen.** The side-by-side wish/skewer layout left virtually no text width at 320 pixels. Secret wishes and riddles now use a full-width row, with the skewer beneath them. A regression checks readable text width and space remaining for the board.

- **P2 — A delayed first animation frame could briefly hide all fruit.** A requestAnimationFrame timestamp can predate renderer construction after a long loading frame. The negative delta rewound simulation time, making fruit appear not yet born. Frame deltas now clamp to zero as well as the existing upper limit. The browser regression injects an older timestamp and checks that time and fruit visibility stay valid.

The existing finale reload checkpoints and GPU disposal fixes remain covered. Core rules keep fruit identities independent of display text. Existing tests verify two/three/four-fruit merges, previews, protected wish fruit in chains, exactly three fruit per skewer, rewards granted once, three-action deliveries, board capacity, five-chapter completion, stars, replay records and save recovery.

## English and Vietnamese

Language is a separate saved presentation preference. Both title and Settings offer a native touch/keyboard selector. Story, letters, riddles, hints, fruit names, goals, rewards, help, controls and accessible labels are translated. Numbers use the selected locale. Switching languages preserves rules, score, progress, Undo and cinematic cues. English is the default and fallback. Original archived game modes remain English and are labelled accordingly in Vietnamese.

Static DOM bindings preserve controls and listeners. Dynamic renderers translate complete messages with named placeholders. Translation tests require coverage of all story/chapter/fruit strings and literal UI keys, and matching placeholder sets. Browser tests audit static labels, exercise mouse/touch merges and Undo across language switches, verify persistence, and inspect portrait/landscape layouts and the final letter.

Physical-device performance and player retention have not been measured by this review. Automated viewport checks are not a substitute for playtesting on actual phones.
